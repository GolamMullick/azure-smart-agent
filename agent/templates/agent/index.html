API ENDPOINTS
POST /api/chat/
Send a message to the AI agent. Supports multi-turn conversation with session management.
GET /api/session/<id>/
Retrieve full chat history for a session from the database.
DELETE /api/session/<id>/clear/
Clear all messages in a session while preserving the session record.
GET /api/health/
Health check — returns model name, endpoint and available tools list.
